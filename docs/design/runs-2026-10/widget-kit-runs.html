Can WoW: Forever draw this?

Forever runs the modern Mainline client and API (the Midnight 12.x rules), not the old Classic Era one. That means the full modern widget set is there: masks, gradients, animation groups, ScrollBox lists, custom fonts. The Midnight restrictions are about combat data and messages during encounters; none of them stop a friends/activity window. Verify each item against the live Forever build before building.

Runs in game → how to build it

The addon can't reach the internet. Runs come in through a file the uploader writes, or from a friend's addon. Everything the player does in game reaches the site after the game saves (/reload or logout) and the uploader sends it.

Framework advice

Keep Ace3 for the plumbing: AceAddon, AceDB (profiles), AceComm, AceConsole. They have nothing to do with the look.
Drop AceGUI for the window. Its widgets carry Blizzard's default skin; restyling means overriding every widget. Native frames + Mixins + ScrollBox give full control and are what Blizzard itself uses now.
Build a small own kit (“DoomKit”): Window, Tab, ListRow, SkillBar, Button, Checkbox, Toast, ClassPortrait.
Settings: native Settings API with our canvas, not AceConfig dialogs.

Sizes in game

Main window 880 × 600 at UI scale 1, resizable down to 700 × 480.
Text never below 11 px; body 13, names 14–24 (Marcellus), headers 14–18 (Marcellus SC).
Rows 28 px, buttons 26–30 px, portraits 20 / 32 / 52 px.
Same colour tokens as the site and the uploader, so all three feel like one product.
