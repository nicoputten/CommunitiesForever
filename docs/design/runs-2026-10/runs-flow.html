Runs · how it travels

Ask now lives in the game and is answered within minutes. A planned run is owned by the website, talked about in Discord, and turns into a party invite in the game at start time. The game never talks to the internet itself: it only learns new things at login or /reload, from a file the uploader writes, or from a friend's addon.
