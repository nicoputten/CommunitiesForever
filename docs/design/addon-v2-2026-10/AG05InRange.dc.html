How the tab fits together

1Left list, two parts: Planned runs on top (compact rows, role pips), then In range for <your character>: every dungeon whose range fits the character you are logged in on, with how many friends’ characters fit, your quest count, and a gold “1 run” tag when a run is planned for it. The ⓘ says “Ranges are typical levels; the list follows the character you’re on.”
2Picking a run shows the run (boards A–C). Picking a dungeon shows the suggested group, who is online and fits, the dungeon’s quests and the two actions. If a run exists for it, “1 run planned · Fri 20:00 ›” jumps to that run.
3Suggested group: one character per friend, best fit for each role from synced and website data; “nobody in range” with the closest character when a role can’t be filled; your other characters in range listed under it.
4Quests from QuestieDB for this dungeon and your faction: ✓ in your log, ! where to pick it up, struck through when done (C_QuestLog.IsQuestFlaggedCompleted), and who else has it from sync data.
5Ask now for <dungeon> opens the existing Ask now dialog with the dungeon filled in; Plan a run… opens the existing in-game plan dialog with the dungeon filled in.
6The empty state (board D) now points to this list instead of the website.
