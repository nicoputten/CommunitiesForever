Addon · what an addon frame can really draw

The rules behind the v2 designs, so Claude Code builds exactly what you see. Atlas names are Mainline 12.x; check each with /dump C_Texture.GetAtlasInfo("name") on WoW: Forever and fall back to a plain coloured square if one is missing.

FrameSquare corners, 1 px gold edge (BackdropTemplate, edgeSize 1) and the 4 corner diamonds you already have. No rounded corners, blur or drop shadows: those need textures and look off at UI scale.
TextYour shipped Marcellus SC for titles and tabs, Inter for the rest (CreateFont). FontStrings can’t do letter-spacing or mixed weights inside one string; use separate FontStrings or |cffRRGGBB colour codes. Truncation: SetWordWrap(false) + width gives “…”, so give names enough room instead.
Class iconsclassicon-<class> atlas (e.g. classicon-paladin) at 18–32 px; round with CreateMaskTexture if wanted.
Role iconsUI-LFG-RoleIcon-Tank, -Healer, -DPS (or roleicon-tiny-* at 16 px). Dimmed (SetDesaturated + alpha .45) for open slots.
Check boxesA 18 px square Texture with SetColorTexture plus the atlas common-icon-checkmark, or ReadyCheck-Ready. Not the default UICheckButton: it is a toggle, these are read-only.
BarsStatusBar 6 px high, 140 px wide, flat colour: gold for counts, green PvE, red PvP.
Role pips5 Textures of 14 × 6 px, coloured per role when filled, dark with a 1 px edge when open.
Online & fitsC_Club.GetClubMembersInfo on the CommunitiesForever club: presence (online), level, classID, zone of the logged-in character. Filter by the run’s level range.
Invite / WhisperInvite: C_PartyInfo.InviteUnit(name) on a button click, out of combat. Whisper: ChatFrame_SendTell(name) opens the chat box; the player types and sends. The addon never sends chat text itself.
Copy a linkAn EditBox that selects its text on focus (HighlightText()); the player presses Ctrl+C. No clipboard API exists.
TooltipsGameTooltip for “swapped: the original goal”, open slots (“3 online fit: …”) and the role pips.
SizesWindow 1080 × 720 at UI scale 1, left list 290 px, rows 34–40 px, buttons 28 px high (32 for the main action). Everything clickable gets a highlight texture on hover.
Not possible hereCombat-log details (Midnight hides them), web requests, opening a browser, posting to Discord. Answers travel to friends online via addon messages and to the site with the next upload.
