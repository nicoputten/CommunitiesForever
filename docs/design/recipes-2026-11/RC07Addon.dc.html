How the link works

1Each scan stores the link from C_TradeSkillUI.GetTradeSkillListLink() per profession and shares it like the other character data. Re-saved on every scan, so a long (stored) link never shows an old list for long.
2Click = SetItemRef on that link: Blizzard’s own profession window opens with Mira’s recipes. Shift-click inserts it in the open chat box, the player sends it.
3Offline: still untested. If offline links fail, dim the link and show the offline tooltip; if they work, both states look like the online one.
4No recipe list or search in the addon; that’s the website and DoomBot. Gathering and Fishing have no link.
